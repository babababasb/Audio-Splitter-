# Audio Splitter (音频切片工具)

一款基于 Java 平台开发的现代化、高精度音频无损切片工具。系统内置 FlatLaf 暗黑界面，专为高效、高精度的音频剪辑与分段需求设计。通过内嵌 FFmpeg 核心引擎，实现免配置、开箱即用的本地化音频处理能力。

## **开发背景**

在处理音频剪辑、数据集制作、语音识别（ASR）语料预处理等场景中，高频的音频切片是一项基础且繁琐的任务。然而，现有的解决方案存在以下痛点：
*   **工具繁复臃肿**：传统音频编辑软件（如 Audition、Audacity）体积庞大、启动缓慢，且针对批量秒数切片的操作路径过长。
*   **命令行门槛高**：底层工具（如 FFmpeg）虽功能强大，但命令行参数配置繁琐，对非技术背景用户极不友好。
*   **环境配置复杂**：部分轻量级切片工具依赖用户手动安装外部解码器，并需要配置复杂的系统环境变量，极易因路径问题导致运行失败。
*   **工程化管理缺失**：切片后的碎片文件缺乏自动化的归档与命名机制，后期整理耗时费力。

因此，Audio Splitter 的开发初衷是解决上述痛点，在保留底层引擎强大性能的同时，提供一个**零依赖、高精度、可视化**的一站式音频切片方案。

## **核心能力**

### **现代化运行环境与集成**
*   **开箱即用**：内嵌 FFmpeg 核心音频引擎，运行时自动静默释放，无需用户手动安装任何环境变量或额外依赖。
*   **高兼容性内核**：基于 Java 8 开发，具备极佳的跨版本兼容性，在现代硬件环境下运行轻量、高效。
*   **100% 本地化处理**：所有音频解码、切片与导出工作均在本地完成，不上传任何数据，保障音频资产隐私安全。

### **高精度无损切片**
*   **格式全兼容**：支持 MP3, WAV, FLAC, M4A, AAC, OGG 等几乎所有主流音频格式的导入与解析。
*   **无缝切片技术**：支持自定义高精度秒数分割（支持小数点），提供高品质 WAV 格式导出或保留原始音频编码的无损导出选项。
*   **自动工程化**：引入“工程”级文件管理。系统根据输入的“工程名称”，自动在输出目录创建独立文件夹，对分割后的音频片段进行有序编号归档。

### **人性化交互设计**
*   **全局拖拽导入**：支持将电脑中的音频文件直接拖入软件界面的任意位置，实现一键无感导入。
*   **现代暗黑 UI**：基于 FlatLaf 现代暗黑皮肤打造，完美适配高分辨率（HiDPI）屏幕，视觉体验精致、流畅。

## **安装部署**

### **获取程序**
请前往本仓库的 [Releases 页面](https://github.com/babababasb/Audio-Splitter-/releases) 下载最新的绿色单文件版 `AudioSplitter.exe` 或可执行 Jar 包。

### **执行与操作步骤**
1.  **启动程序**：本软件为**绿色免安装版**，双击 `AudioSplitter.exe` 即可直接运行。
2.  **引擎初始化**：首次运行时，软件会在后台自动释放内嵌的音频引擎，请在看到状态栏显示 **“音频引擎就绪”** 后开始使用。
3.  **导入音频**：直接将音频文件拖入软件窗口，或者点击 **“浏览”** 按钮手动选择目标音频。
4.  **配置路径与参数**：
    *   选择分割后的工程文件夹存放位置（输出路径）。
    *   填写 **工程名称**（系统将以此名称新建文件夹）。
    *   设置 **单段分割秒数**（支持浮点数，如 `5.5`）。
    *   选择 **输出格式**（高品质 WAV 或 保持原格式）。
5.  **执行分割**：点击底部的 **“开始分割音频”**，稍等片刻即可在输出目录中看到自动生成的工程文件夹及切片文件。

## **开发者指南**

如果您想对本项目进行二次开发或自行通过源码编译，请遵循以下步骤：

### **环境准备**
*   **Java JDK**: 推荐使用 JDK 8 或更高版本。
*   **IDE**: 推荐使用 IntelliJ IDEA。
*   **构建工具**: Maven 3.6 及以上。

### **获取源码与引擎**
1.  克隆本项目到本地：
    ```bash
    git clone https://github.com/babababasb/Audio-Splitter-.git
    ```
2.  下载适用于 Windows 的 FFmpeg 运行时（`ffmpeg.exe`）。
3.  在项目资源目录下创建 `bin` 目录，并将 `ffmpeg.exe` 放入以下路径：
    ```text
    src/main/resources/bin/ffmpeg.exe
    ```

### **编译打包**
1.  在项目根目录下执行以下 Maven 命令进行清理与打包：
    ```bash
    mvn clean package
    ```
2.  编译成功后，在 `target/` 目录下会生成带所有依赖的胖 JAR 包：
    ```text
    target/6s_music-1.0-SNAPSHOT-jar-with-dependencies.jar
    ```
3.  您可以使用 **Launch4j** 等工具，将该 JAR 包转换并打包为最终的 `.exe` 可执行文件。

## **常见问题**

### **系统提示「无法释放音频引擎」或状态栏无响应**
*   请检查当前用户对系统临时目录（`Temp` 目录）是否拥有写入和执行权限。
*   部分杀毒软件可能会误拦截静默释放的二进制文件，若出现此情况，请在杀毒软件中添加信任或退出后重试。

### **拖拽音频文件到界面没有反应**
*   请勿以“管理员身份”运行本程序。Windows 的安全机制（UAC）会阻止低权限进程（如资源管理器）向高权限进程（管理员运行的程序）拖拽传输文件。

### **双击 .exe 提示 "This application requires a Java Runtime Environment..."**
*   本软件基于 Java 编写，运行需要系统安装有 Java 运行环境。请前往 [Oracle 官网](https://www.oracle.com/java/) 或采用 [Adoptium OpenJDK](https://adoptium.net/) 安装 Java 8 或更高版本的 JRE/JDK。

### **分割出的音频文件大小为 0 字节或无法播放**
*   请检查原始音频文件是否损坏，或尝试先将其转为标准 WAV 格式再导入软件进行切片。
*   确保分割秒数输入框中填写的是合法的数字，且不为 0。
